# Веб-приложение для поддержки принятия решений в агробизнесе «АгроТрендикс» (AgroTrendix)

## Назначение системы
**«АгроТрендикс» (AgroTrendix)** — информационно-аналитическое веб-приложение, предназначенное для фермеров, экономистов и руководителей крестьянских (фермерских) хозяйств. Система обеспечивает сбор и наглядный анализ рыночных цен на сельскохозяйственную продукцию, оценку ценовой динамики по регионам России, автоматизированный расчёт потенциальной выручки от реализации урожая, а также моделирование и сравнение альтернативных сценариев реализации сырья и готовой продукции переработки.
