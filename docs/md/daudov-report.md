## 1. Введение и назначение роли
В рамках командного проекта «АгроТрендикс» на меня была возложена ответственность за контроль качества, разработку тестовых сценариев и моделирование прецедента межрегионального сравнения цен.

## 2. Детальное описание выполненных работ
### 2.1. Разработка тестовой документации
Разработаны спецификации проверок для ключевых функций системы: валидация формата загружаемых файлов цен и контроль корректности работы расчетного калькулятора.

### 2.2. Спецификация Use Case сценариев
Мной был детально описан сценарий:
1. **UC-04 «Сравнение цен по регионам»:**
   - *Актор:* Фермер / Аналитик.
   - *Основной поток:*
     1. Пользователь выбирает интересующую культуру и несколько субъектов РФ.
     2. Система запрашивает архив цен по выбранным регионам за указанный период.
     3. Система сопоставляет уровни цен, рассчитывает межрегиональную разницу (спред) и выводит сравнительную таблицу с графиком.

### 2.3. Разработка UML-диаграмм
Построена диаграмма последовательности для сценария сравнения региональных цен (sd04_compare.puml / image6.png), включающая проверку наличия данных по регионам.

## 3. Заключение
Тестовые спецификации и проработанный сценарий сравнения цен обеспечивают корректное функционирование аналитического блока системы.
