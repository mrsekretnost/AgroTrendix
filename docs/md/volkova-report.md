## 1. Вариант использования UC-02 «Расчёт потенциальной выручки»

**Автор:** Волкова А. П.

**Предусловия:** Пользователь авторизован с ролью «Фермер», в базе данных содержатся актуальные ценовые данные.

**Охваченные потоки:** основной поток (успешный расчёт выручки), альтернативный поток A1 (незаполненные поля или объём ≤ 0) и альтернативный поток A2 (отсутствие ценовых данных).

### 1.1. Последовательность взаимодействия (SD-02)

**Участники:** Фермер и Система.

1. **Фермер → Система:** открыть раздел расчёта выручки.
2. **Система → Фермер:** отобразить форму выбора продукции, региона и ввода объёма.
3. **Фермер → Система:** выбрать культуру, регион и ввести объём.
4. **Фермер → Система:** нажать «Рассчитать выручку»; система проверяет введённые данные.

### 1.2. Альтернативные потоки и успешный расчёт

**A1 — поля не заполнены или объём ≤ 0.**  
5. **Система → Фермер:** вывести сообщение об ошибке: «Введите положительное число».

**A2 — ценовые данные отсутствуют.**  
6. **Система → Фермер:** вывести сообщение об ошибке: «Данные по региону и культуре отсутствуют».

**Основной поток — данные корректны.**  
7. **Система:** запросить цену из базы данных и рассчитать потенциальную выручку по формуле:

   **Потенциальная выручка = объём × цена.**

8. **Система → Фермер:** отобразить итоговую выручку и параметры расчёта.

**Пояснение к ветвлению:** В диаграмме SD-02 предусмотрены три взаимоисключающие ветви: A1 при незаполненных полях или неположительном объёме, A2 при отсутствии ценовых данных и основной поток при корректных данных. В последнем случае система выполняет расчёт и показывает результат.
