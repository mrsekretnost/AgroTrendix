# Правила работы над проектом «АгроТрендикс»

1. Основная ветка репозитория называется main.
2. Изменения выполняются в тематических ветках (например, docs/*, eature/*, ix/*).
3. Сообщения коммитов должны быть понятными и отражать суть изменений.
4. Перед объединением изменений в main проводится взаимная проверка (Pull Request / Review).
5. Перед сдачей работы Markdown-отчёты и Word-версии (.docx) обязательно сверяются на идентичность содержимого.
